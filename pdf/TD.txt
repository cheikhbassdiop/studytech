📘 1. RÉSUMÉ DU COURS : INTRODUCTION À LINUX
🐧 Définition
Linux est un système d’exploitation open source
Créé en 1991 par Linus Torvalds
Il permet de :
gérer le matériel
exécuter des programmes
organiser les fichiers
📜 Historique
1991 : création de Linux
1992 : devient open source
2004 : lancement de Ubuntu
Aujourd’hui : très utilisé dans les serveurs et le cloud
⚙️ Importance de Linux
Gestion du matériel
Sécurité élevée
Gestion des utilisateurs
Utilisé dans :
serveurs 🌐
Android 📱
banques 🏦
cloud ☁️
📦 Distribution
Linux = noyau seulement
Distribution = noyau + logiciels + interface
Exemples :
Ubuntu
Debian
Fedora
Kali Linux
🧠 Architecture
Utilisateur
Applications
Noyau
Matériel

👉 Le noyau gère :
CPU
mémoire
disque

📁 Structure des dossiers
/ : racine
/home : utilisateurs
/etc : configuration
/var : logs
/usr : programmes
/bin : commandes

💻 Commandes de base
pwd : dossier actuel
ls : afficher fichiers
cd : changer dossier
mkdir : créer dossier
touch : créer fichier
rm : supprimer
